# 微信支付APIv3密钥设置指南

## 📍 设置位置

### 1. 登录微信商户平台
- 网址：https://pay.weixin.qq.com
- 使用您的商户号登录

### 2. 导航到API安全设置
```
产品中心 → 开发配置 → API安全 → APIv3密钥
```

### 3. 查看当前APIv3密钥
在APIv3密钥页面，您会看到：
- 当前密钥状态（已设置/未设置）
- 密钥创建时间
- 重置密钥按钮

## 🔧 操作步骤

### 查看现有密钥
1. 在APIv3密钥页面，点击"查看"或"管理"
2. 系统会显示当前设置的32位密钥
3. 对比您的 `.env` 文件中的 `WECHAT_PAY_APIV3_KEY`

### 重置APIv3密钥（推荐）
1. 在APIv3密钥页面，点击"重置"
2. 进行身份验证（可能需要扫码或短信验证）
3. 系统生成新的32位密钥
4. **立即复制并保存新密钥**
5. 更新您的 `.env` 文件

## ⚠️ 重要注意事项

### 密钥格式要求
- **长度**：必须是32位字符
- **字符**：支持字母和数字
- **示例**：`7aK9F3xQ2zT5bP8sL4vG6nH1dJ0wE2rY`

### 安全建议
1. **定期更换**：建议每3-6个月更换一次
2. **安全存储**：不要在代码中硬编码，使用环境变量
3. **权限控制**：只有必要人员可以访问密钥

## 🔄 更新密钥后的步骤

### 1. 更新代码配置
```bash
# 更新 .env 文件
WECHAT_PAY_APIV3_KEY=你的新密钥
```

### 2. 重启服务
```bash
npm start
```

### 3. 测试支付
- 完成一笔测试支付
- 确认回调处理正常

## 🆘 常见问题

### Q: 为什么APIv3密钥会不匹配？
A: 可能原因：
1. 密钥已过期
2. 商户平台重置了密钥但代码未更新
3. 使用了错误的商户号

### Q: 重置密钥会影响现有订单吗？
A: 不会，重置密钥只影响新的API调用和回调验证

### Q: 忘记密钥怎么办？
A: 只能重置密钥，微信不会显示已设置的密钥明文
