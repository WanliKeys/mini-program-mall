# 微信支付测试指南

## 🎯 测试环境对比

### 微信开发者工具测试
- **适用场景**: 开发阶段，测试前端逻辑
- **支付状态**: 模拟数据，非真实支付
- **回调测试**: ❌ 无法测试
- **推荐度**: ⭐⭐

### 真机测试（开发版）
- **适用场景**: 本地开发，真实支付测试
- **支付状态**: ✅ 真实支付
- **回调测试**: ✅ 可测试（需要ngrok）
- **推荐度**: ⭐⭐⭐⭐

### 体验版测试
- **适用场景**: 预发布验证
- **支付状态**: ✅ 真实支付
- **回调测试**: ✅ 可测试（需要生产环境）
- **推荐度**: ⭐⭐⭐⭐⭐

## 🚀 推荐测试步骤

### Step 1: 开发者工具初步测试
```bash
# 1. 确保后端服务运行
npm start  # 确保端口3000运行

# 2. 微信开发者工具中
# - 打开小程序
# - 选择商品
# - 点击支付
# - 查看控制台日志
```

**预期结果**: 支付接口调用成功，但无法完成真实支付

### Step 2: 真机测试（推荐）
```bash
# 1. 确保ngrok运行（用于回调）
ngrok http 3000

# 2. 更新回调地址（如果ngrok地址变化）
# 编辑 .env 中的 WECHAT_PAY_NOTIFY_URL

# 3. 微信开发者工具中
# - 点击"预览" → 生成二维码
# - 用手机微信扫码打开
# - 进行真实支付测试（0.01元）
```

**预期结果**: 完整的支付流程，包括回调处理

### Step 3: 验证支付结果
```bash
# 检查支付记录
node check-payment-records.js

# 查看最新支付状态
tail -f logs/app.log
```

## 🔍 测试检查点

### 前端检查
- [ ] 支付按钮点击响应
- [ ] 支付参数正确传递
- [ ] 支付界面正常调起
- [ ] 错误处理正常显示

### 后端检查
- [ ] 支付订单创建成功
- [ ] 微信支付返回正确参数
- [ ] 支付接口调用无错误
- [ ] 日志记录完整

### 支付流程检查
- [ ] 用户支付成功
- [ ] 微信回调正常接收
- [ ] 订单状态更新为"已完成"
- [ ] 卡密分配成功（如是虚拟商品）

## 📱 真机测试详细步骤

### 1. 准备工作
```bash
# 确保服务运行
pm2 status  # 查看后端服务状态

# 确保ngrok运行
curl https://lora-confarreate-samella.ngrok-free.dev/health
```

### 2. 生成测试二维码
- 微信开发者工具 → 点击"预览"
- 选择"自动更新"或"手动更新"
- 生成二维码

### 3. 手机扫码测试
- 使用微信扫码
- 允许获取用户信息
- 进行商品浏览和支付测试

### 4. 支付测试
- 选择小额商品（0.01元）
- 点击支付
- 完成微信支付流程
- 观察订单状态变化

## ⚠️ 注意事项

### 开发环境测试
- **支付金额**: 建议使用0.01元测试
- **回调地址**: 必须使用ngrok等公网地址
- **网络环境**: 确保手机和服务器网络通畅

### 真实支付
- **资金安全**: 测试时使用小金额
- **退款处理**: 如需退款，在商户平台操作
- **记录保存**: 保存测试订单号以便查询

## 🆘 常见问题

### Q: 开发者工具中支付失败？
**A**: 正常现象，开发者工具不支持真实支付

### Q: 真机扫码后无法访问接口？
**A**: 检查ngrok状态和防火墙设置

### Q: 支付成功但订单状态未更新？
**A**: 检查回调URL配置和服务器日志

### Q: 如何进行大量测试？
**A**: 使用微信支付沙箱环境或联系微信开通测试权限
